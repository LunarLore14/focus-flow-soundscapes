# Focus Flow & Soundscapes

A polished productivity dashboard with:
- Pomodoro timer with focus and break modes
- Ambient browser-generated sound mixer
- Embedded study playlist options
- Task list sidebar
- Floating habit tracker
- Circular timer ring
- Custom playlist categories
- Daily focus summary popup
- Local state persistence with `localStorage`

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. If you want to view it through a local server, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Features

- ADHD and dyslexia helper modes
- Start / pause / reset / skip pomodoro controls
- Progress tracking and session history
- Custom audio upload support
- Persistent notes, tasks, habits, and settings

## Notes

This app is built as a static front-end, so no install step is required beyond opening the page in a browser.
